### What I ship

Tools that make Claude projects easier to manage, track, and ship — especially if you're newer to software engineering.

| Repo | Problem It Solves |
|------|-------------------|
| [**shiplog**](https://github.com/grAIcetech/shiplog) | Requests scatter across dozens of Claude sessions. Within a week you can't remember what's done, what's open, or where the output landed. This gives you a single filterable dashboard — no server, no database, just one HTML file. |
| [**prompt-coach**](https://github.com/grAIcetech/prompt-coach) | Most Claude users don't know the 12 official prompting best practices, and even experienced users forget to apply them. This skill watches how you prompt and quietly suggests one improvement per response — like having a colleague point out a better way in real time. |
| [**shiplog-widget**](https://github.com/grAIcetech/shiplog-widget) | You build 10+ things in a Claude session and can't remember what shipped by the time the chat closes. This skill renders a visual session recap across Dispatch, Claude.ai, Claude Code, and Notion — all from one JSON file. |
| [**renderrepo**](https://github.com/grAIcetech/renderrepo) | AI-generated visuals get lost in random folders with no record of the prompt that made them. This logs every image with project, prompt, location, and publish status so creatives never lose a visual again. |
| [**agentic-auth**](https://github.com/grAIcetech/agentic-auth) | Most apps only know how to authenticate humans, not AI agents. This skill auto-generates auth.md files so every app you build is agent-ready from day one. Based on the [WorkOS open protocol](https://workos.com/auth-md). |
